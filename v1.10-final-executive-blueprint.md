# v1.10 — Final Executive Blueprint

**Synthesis of v1.1-v1.9.** A single action plan: what to build, in what order, and how to know it's working.

---

## The Product

**A SaaS & Business Operations Calculator Suite** — 50 interactive calculators for SaaS founders, operators, and finance teams. Free to use, freemium Pro for power features, monetized via display ads + subscriptions + affiliate + API.

## The Metrics That Matter

**Monthly recurring revenue (MRR)** — the only metric that answers "is this working?"

| Metric | Target (Month 6) | Target (Month 12) |
|--------|-----------------|------------------|
| Total calculators | 26 (EN) + 130 (5 languages) | 38 (EN) + 380 (10 languages) |
| Blog posts published | 28 | 60 |
| Indexed pages | 200+ (with multi-language) | 500+ |
| Keywords ranking | 200+ | 1,000+ |
| Monthly sessions | 4,000 | 15,000-30,000 |
| Ad RPM (AdSense → Journey) | $4 | $6 |
| Freemium registered users | 200 | 800+ |
| Freemium Pro conversions | 3 (1.5%) | 16 (2%) |
| Embed sites | 10 | 50 |
| Referring domains | 20 | 60+ |
| Email subscribers | 500 | 2,000+ |

### Health Metrics
- **Ad blocker rate**: If > 60%, accelerate server-side ads
- **Bounce rate**: If > 60%, improve content depth
- **Avg session duration**: If < 2 min, add more interactive features
- **Page load time**: If > 2s, audit Core Web Vitals
- **Freemium conversion**: If < 1%, A/B test feature gating

## The Risk Dashboard

### Watch Items (Monthly Check)
- [ ] RPM trend: increasing or stable? (If declining 2+ months, accelerate non-ad revenue)
- [ ] Traffic trend: month-over-month growth? (If flat 2+ months, double down on SEO)
- [ ] Freemium conversion: > 1.5%? (If below, test new pricing/features)
- [ ] Google core update: Any announced? (Pause non-essential work, audit site)
- [ ] Competitor activity: Any new entries? (Check HustleCalcs, new calculator sites)
- [ ] AdSense account: Any warnings? (Resolve immediately if flagged)

### Kill Switches
- **If RPM < $3 at 10K sessions**: Pivot to subscription-primary model, deprioritize ad optimization
- **If traffic < 500 sessions at month 6**: Invest in paid link-building or pivot keyword strategy
- **If freemium conversion < 0.5% at 500 registered users**: Make Pro exclusively about "no ads" and data export
- **If burnout risk is high (month 3+)** : Hire first freelancer before it affects quality
