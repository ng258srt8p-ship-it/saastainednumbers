### 2b. Fix CLS (layout shift) — add min-height containers

### Priority
High — prevents page reflow, protects Core Web Vitals

### Files Changed
1. `lib/ads.ts` — add dimension constants per placement
2. `components/AdSlot.tsx` — apply min-height via style attribute

### Changes

**lib/ads.ts** — add:
```ts
export const AD_DIMENSIONS: Record<AdPlacement, { minHeight: number }> = {
  "below-results": { minHeight: 90 },
  "between-sections": { minHeight: 90 },
  sidebar: { minHeight: 250 },
  footer: { minHeight: 90 },
  "sticky-footer": { minHeight: 50 },
};
```

**components/AdSlot.tsx** — add inline style:
```tsx
const dims = AD_DIMENSIONS[placement];
<div style={{ minHeight: dims.minHeight }} className="...">
  {/* ad content */}
</div>
```

### 2d. Sticky footer — add close button

### Priority
Medium — required for Better Ads Standards compliance on mobile

### File Changed
1. `components/AdSlot.tsx`

### Changes
Add a close (X) button for the sticky-footer placement that sets a localStorage flag:

```tsx
const [dismissed, setDismissed] = useState(() => {
  if (typeof window === "undefined") return false;
  return localStorage.getItem(`ad-dismissed-${slug}`) === "true";
});

const handleDismiss = () => {
  setDismissed(true);
  localStorage.setItem(`ad-dismissed-${slug}`, "true");
};

if (dismissed) return null;
```

The close button renders as a small `×` in the top-right corner of the sticky footer, with `aria-label="Close ad"`.

The slug is passed via a new `slug` prop on `AdSlot`.

## Phase 3: AdSense Setup (User Action Required)

### Steps
1. Go to `https://adsense.google.com` and sign up
2. Get your publisher ID (looks like `ca-pub-XXXXXXXXXXXXXXXX`)
3. Add to environment:
   ```bash
   NEXT_PUBLIC_ADSENSE_ID=ca-pub-XXXXXXXXXXXXXXXX
   ```
4. Deploy

### No code changes needed
The existing `lib/ads.ts` and `components/AdSlot.tsx` already handle AdSense rendering when `NEXT_PUBLIC_ADSENSE_ID` is set. The `<ins>` tag is already wired with:
```html
<ins className="adsbygoogle"
  data-ad-client={adsConfig.adSense.publisherId}
  data-ad-slot={...}
  data-full-width-responsive="true"
/>
```
