# SEO Rank Diagnosis: "Free SaaS Calculators"

## Diagnosis Summary

`site:saastainednumbers.com` returned only the homepage in Google's index — none of the 86 calculator pages, 32 blog posts, or 9 category pages were discoverable.

## Root Causes & Fixes Applied

### 🚨 Critical: Sitemap Bug (Fixed)

`app/sitemap.ts` called `getAllCalculators()` but never imported `@/calculators/config/_all` to populate the registry. Every other page imported `_all.ts`; the sitemap was the only exception.

**Fix**: Added `import "@/calculators/config/_all"` to `app/sitemap.ts`.

**Impact**: Production sitemap went from **41 URLs** to **219 URLs** (86 calc pages + 86 embed pages + 9 categories + 32 blog posts + 6 static pages). 173 calculator-related URLs now discoverable by Google.

### 🚨 Critical: Content Not Visible to Crawlers (Fixed)

Calculator pages used `"use client"` components for all content rendering. Next.js App Router with static export serializes page content as RSC flight data (not visible HTML). Google saw only nav/footer (~461 chars on the page body).

**Fix**: Created `app/[category]/[slug]/layout.tsx` — a server-only nested layout that renders:
- Editorial content (intro, how-to, formula, benchmarks, FAQs) as visible HTML
- JSON-LD structured data (WebApplication, HowTo, FAQPage) in visible HTML
- The page's CalculatorClient as `{children}` (still client-rendered, but with `hideContent` prop to prevent duplication)

**Impact**: Visible text went from **461 chars → 6,000+ chars**. JSON-LD schema now in visible HTML head region (before flight data).
