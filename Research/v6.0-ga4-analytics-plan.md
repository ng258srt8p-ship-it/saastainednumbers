3. Verify in GA4 Realtime report within 24 hours

| Check | Where | What to look for |

## Phase 3: Funnel & Competitive Analysis (2+ weeks of data)

### Funnels to Build in GA4

1. **Homepage to Calculator**: `page_view` on `/` → `page_view` on `/[category]/[slug]` → `calculate_tool`
   - *Question*: What % of homepage visitors reach a calculator? Where do they drop off?

2. **Calculator to Share/Embed**: `calculate_tool` → `share_tool` or `embed_generate`
   - *Question*: Which calculators earn the highest share/embed rates? (Viral candidates)

3. **Search to Calculator**: `search` event with query → `page_view` on a calculator page
   - *Question*: What are users searching for that they can't find? (Content gap)

## Phase 4: Design Improvements (Driven by Data)

### When to Act

| Signal | Threshold | Action |
|--------|-----------|--------|
| Homepage → calculator drop-off | > 60% exit from homepage | Add category descriptions, move search above fold, add popular calculators section |
| Calculator non-interaction | > 40% of calculator page visitors don't calculate | Add input placeholder hints, auto-focus first field, show default results immediately |
| Compare mode adoption | < 5% of calculators use compare | Move toggle above fold, add "vs baseline" prompt, highlight comparison value |
| Mobile bounce rate | > 65% on mobile | Optimize calculator inputs for touch, reduce layout shift, check Core Web Vitals |
| Language split | > 15% non-English traffic | Prioritize translation for that locale, add locale switcher |
| Zero-embed calculators | Any calculator with 0 embed_generate events | Expose embed button more prominently, add embed CTA in results section |
| Low search match rate | > 30% of searches return 0 results | Build calculators for the most common unmatched queries |

### Review Cadence

- **Daily** (2 min): Realtime check — see Daily Check above
- **Weekly** (15 min): Log events, top content, anomalies
- **Monthly** (30 min): Funnel analysis, compare adoption, search gaps
- **Quarterly** (1 hr): Competitive benchmark refresh, update moat table
