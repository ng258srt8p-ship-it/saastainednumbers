## Competitive Edge Features

### 1. Side-by-Side Scenario Comparison (IMPLEMENTED)
Every calculator now has a "Compare Scenarios" mode that allows users to run two sets of inputs side by side with delta indicators and a bar chart overlay. This turns any calculator into a what-if modeling tool — a capability no free calculator site offers.

### 2. Chart Visualization (IMPLEMENTED)
Recharts grouped bar charts on every calculator in Compare mode, using brand colors (teal `#008387` for Scenario A, navy `#143562` for Scenario B).

### 3. URL-Persisted Dual State (IMPLEMENTED)
Both scenarios persist in URL params using `_b` suffix (e.g., `?customers=100&arpu=50&customers_b=200&arpu_b=75`), making comparisons shareable and bookmarkable.

## UX Pattern Research for Mobile Comparison Layout

Sources studied:
- Nielsen Norman Group — "Comparison Tables for Products, Services, and Features"
- Cloudscape Design System (AWS) — "Split View" pattern
- Boundev — "Split-Screen Design & Motion for Web Interfaces"
- Shopify — mobile comparison table (columns → tabs)
- OmniCalculator — cell phone plan comparison (vertical stack)
- Automate & Tweak — AI tools comparison (floating bar + vertical mobile)
- NN/G — "12 Design Recommendations for Calculator and Quiz Tools"

### Key Findings

1. **Universal mobile pattern**: Stack vertically below 768px breakpoint. Side-by-side columns become unreadable on mobile (NN/G, Boundev, Cloudscape all agree).

2. **Never force horizontal scroll**: Shrinking columns to fit side-by-side destroys readability. Vertical stack is the only viable approach.

3. **Delta indicators**: Color-coded badges (green ▲ positive, red ▼ negative) with format toggle (absolute / percent / both) let users choose their preferred view.

4. **Progressive disclosure**: The "+ Add Scenario B" CTA invites users into comparison mode without overwhelming them with dual inputs by default.

5. **Split-screen is desktop-first**: The `lg:flex-row` / `flex-col` Tailwind pattern at 1024px breakpoint provides adequate horizontal space for side-by-side columns.
